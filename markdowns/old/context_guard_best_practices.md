### Design Patterns Identified

| Pattern | Where | Evidence |
|---------|-------|----------|

| **Singleton** | firecrawl-client.ts | Lazy-initialized Firecrawl client instance |

## 4. AI/ML Integration — Score: 9/10

### LLM Strategy

The **dual-LLM fallback** pattern is sophisticated:

1. **Primary:** Anthropic Claude → structured JSON response
2. **Fallback:** Google Gemini 2.5 Flash → `responseSchema` enforcement
3. **Last resort:** Hardcoded demo scenario data

This three-tier resilience is excellent for a production system.

### RAG Implementation

The hybrid search in rag.ts is well-conceived:

- **Phase 1 (Topic-filtered):** `hasAny(topics, [...])` + cosine distance — finds topically relevant articles first
- **Phase 2 (Pure vector):** Fills remaining slots with semantically similar articles regardless of topic
- **Deduplication:** URL-based dedup between phases
- **Threshold:** `cosineDistance <= 0.5` prevents low-quality matches
- **Credibility scoring:** Domain-based scoring (gov.sg=0.95, CNA=0.90, forums=0.70)

### Prompt Engineering

The analysis prompt in `analyze-and-predict.ts` is comprehensive:
- Separates RAG sources (with credibility labels) from live web sources
- Instructs LLM to prioritize high-credibility sources for counter-narratives
- Uses low-credibility sources to understand rumour language
- Requests structured output: risk scores, counter-narratives in 4 languages, policy recommendations, source citations
